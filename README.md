A single fortune cookie line for a crypto trader who has just been liquidated — one that makes them laugh instead of cry. The program writes this fortune to `/output/entry.txt`:

> "A great fortune awaits you — unfortunately, it is currently locked in the margin account you just emptied."

## Run it

```sh
python3 main.py
```

The program is deterministic and stdlib-only: it writes the same single line to `/output/entry.txt` on every run.
